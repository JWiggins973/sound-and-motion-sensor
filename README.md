# Alert Backend

A home alert system. An ESP32 watches a door sensor and a microphone, and
sends an alert (to Discord and to this backend) when the door opens or a
loud noise is detected. The backend saves alerts to a SQLite database and
shows them in a simple web log with filters (today, last 24h, week, door,
loud).
